## Rewrite in TypeScript for React 19

lazymage is now a TypeScript library for React 19. It keeps the API of `react-lazy-load-image-component`. To migrate, change the import.

- Add the `useLazyLoad` and `useImageStatus` hooks.
- Add the `fallbackSrc` prop. It shows one fallback image when `src` fails to load.
- Add the `onReady` prop. It runs when the image is loaded and decoded.
- Add the `preload` prop. It fetches the image early with `react-dom` `preload()`.
- Add the `root` and `scrollMargin` props for scroll containers.
- Add the `data-state` attribute on the image and its wrapper.
- Turn off the effect transitions when the user prefers reduced motion.
- Remove all runtime dependencies.
